# 이력 DB (템플릿)

> 항목 하나 = 한 프로젝트 안의 한 성과. 헤더는 `## EXP-숫자 | 회사 | 직함 | 기간` 형식을 지킨다.
> 필드 값은 한 줄. 모르는 값은 `미확인`으로 적고 지어내지 않는다.

## EXP-001 | <회사> | <직함> | YYYY.MM–YYYY.MM
- 프로젝트: <프로젝트 라벨>
- 원문: <사용자가 말한 그대로>
- 정리: <읽기 쉽게 다듬은 문장. 원문의 의미를 넘지 않는다>
- 역할: led | managed | built | operated | contributed | supported
- 지표: <값> / <단위> / <기간> / <귀속> / <분모 또는 해당없음>
- 키워드: <쉼표로 구분>
- 상태: 확정 | 미검증 | 폐기
- 최종확인일: YYYY-MM-DD
- 출처: 사용자 진술 | <문서명>
- 메모: <같은 프로젝트의 다른 항목과의 관계(사용자가 말한 것만), 고객명 공개 여부 등>

## 필드 설명

| 필드 | 필수 | 설명 |
|---|---|---|
| 프로젝트 | O | 같은 프로젝트 항목을 묶는 라벨 |
| 원문 | O | 사용자의 말 그대로. 수정하지 않는다 |
| 정리 | O | 다듬은 문장 |
| 역할 | O | 위 6개 동사 중 하나 |
| 지표 | 지표가 있으면 O | 값 / 단위 / 기간 / 귀속 / 분모. 지표가 없으면 `없음` |
| 키워드 | O | 대조 분석용 |
| 상태 | O | 확정 / 미검증 / 폐기 |
| 최종확인일 | O | 사용자가 마지막으로 확인한 날 |
| 출처 | O | 사용자 진술 또는 문서명 |
| 메모 | X | 선택 |
